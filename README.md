# ExamenForge
ExamForge es una aplicación móvil desarrollada con .NET MAUI diseñada para estudiantes, cuyo objetivo es centralizar el estudio mediante la organización de asignaturas y la práctica con test generados mediante IA. La herramienta unifica apuntes y preguntas en una colección para facilitar un repaso rápido y estructurado para preparar los examenes.
